# คลังศัพท์พื้นฐาน

เปิดที่เมนู **คำศัพท์ → สมุดศัพท์** หรือ #vocab
หน้าแรกเป็นสารบัญหนังสือภาพ เลือกหมวดเพื่อเปิดอ่านทีละหน้า คอมเห็นสองหน้า มือถือหนึ่งหน้า
พลิกหน้าได้ด้วยปุ่ม ลูกศรคีย์บอร์ด หรือปัดซ้าย/ขวาบนมือถือ เลือกเลขหน้าเพื่อกระโดดได้
อนิเมชันหมุนแผ่นหน้ารอบสันหนังสือ และเปลี่ยนหน้าทันทีเมื่ออุปกรณ์ตั้ง reduced motion
โครงสร้างเพิ่มหมวดใหม่: [VOCABULARY_BOOK.md](VOCABULARY_BOOK.md)
ส่วน **จากบทเรียน** ยังคงแสดงคำที่สะสมจากบทเรียนเดิม

## เนื้อหา 200 รายการ

| หมวด | จำนวน | จุดสำคัญ |
|---|---:|---|
| วัน | 7 | ตัวพิมพ์ใหญ่ และ on + วัน |
| เดือน | 12 | ลำดับเดือน, in + เดือน, on + วันที่ |
| ตัวเลข | 41 | 0–20, 30–90, 100, 1,000, 1,000,000 และลำดับ 1st–10th |
| ผลไม้ | 16 | a/an, fruit รวม ๆ, lemon ต่างจาก lime |
| สัตว์ | 20 | พหูพจน์ fish และ sheep |
| สิ่งของ | 24 | watch/clock, shoes และ glasses เป็นพหูพจน์ |
| ผัก | 16 | ชื่อผักในครัว เช่น carrot, broccoli และ tomato ในบริบทอาหาร |
| สี | 12 | สีที่ใช้บ่อย และ orange ที่เป็นได้ทั้งสีและผลไม้ |
| เสื้อผ้า | 16 | shirt/T-shirt, hat/cap และคำพหูพจน์ pants/jeans |
| ยานพาหนะ | 12 | ชื่อรถและเรือ พร้อม by + ยานพาหนะ |
| สถานที่ | 12 | ร้านค้า สถานี และสถานที่ในเมือง |
| ร่างกาย | 12 | ส่วนสำคัญ รวมทั้ง foot/feet และ hair |

ทุกคำมีความหมายไทย คำอ่านโดยประมาณ ประโยคตัวอย่างและคำแปล
เสียงใช้ Web Speech Synthesis ของอุปกรณ์ เช่นเดียวกับบทเรียนเดิม ไม่ใช่ไฟล์เสียงมนุษย์
คำอ่านไทยช่วยเริ่มต้น แต่แทนเสียงอังกฤษได้ไม่ครบ
ข้อมูลอยู่ใน src/basic-vocabulary.js; ID ใช้ชื่อหมวดและคำอังกฤษ คงที่เมื่อจัดเรียงรายการใหม่

## การทบทวนและข้อมูล

ค้นหาไทย/อังกฤษ/ตัวเลขได้ทั่วทุกหมวด รวมทั้งค้น cafe เพื่อหา café ได้; ปุ่มหมวดล้างคำค้นเพื่อกลับไปดูหมวดนั้น
กรองเฉพาะคำที่ยังไม่ทบทวนได้
ทำเครื่องหมายเอง หรือตอบถูกในแบบฝึก จะเพิ่ม ID ลง basicWordsReviewed
แบบฝึกสุ่มสูงสุด 10 คำจากผลลัพธ์ปัจจุบัน ตัวเลือกอยู่ในหมวดเดียวกันและไม่ซ้ำกัน
หนึ่งข้อรับคำตอบครั้งเดียว แสดงเฉลยพร้อมตัวอย่าง แล้วฝึกเฉพาะคำที่พลาดซ้ำได้
คะแนนแบบฝึกแสดงเฉพาะรอบปัจจุบัน ไม่ใช่คะแนนรับรองระดับภาษา

basicWordsReviewed เป็นชุด ID ที่ normalize ตรวจเทียบกับคลังจริงและ merge รวมข้ามเครื่อง
ใช้ learner_progress.state และนโยบายสิทธิ์เดิม ไม่ต้องเปลี่ยน SQL
รองรับ guest, นำเข้า/ส่งออก, แยกผู้ใช้, reset epoch และการซิงก์แบบเดิม
ไม่เพิ่ม completed, learnedWords, xp หรือ skill ของบทเรียน

## การตรวจสอบ

Node: ความครบและ ID ทั้ง 200 คำ, วันและเดือนเทียบเฉลยที่ตรวจแล้ว, ตัวเลข/ลำดับ, คำสับสน, การค้นหา, ตัวเลือกแบบฝึก และ merge/reset ของความก้าวหน้าศัพท์
Playwright: หมวดทั้งสิบสอง, ค้นไทยและตัวเลข, ส่งข้อความถูกต้องให้ระบบเสียง, คำอ่าน, คำตัวอย่าง, เก็บข้อมูลหลัง reload, แบบฝึก/เฉลย/ลองคำที่พลาด, และความกว้าง 320/768/1440px
เพิ่มการทดสอบบัญชีสองเครื่องและคนละบัญชีด้วย REST จำลอง ขณะเดียวกันคงชุดทดสอบ 32 บทเดิม
