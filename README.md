# English with Yuri

เว็บเรียนภาษาอังกฤษสำหรับคนไทย ตั้งแต่พื้นฐานจนถึงสถานการณ์จริง
https://nuttapon1052-dotcom.github.io/english-learning/

## มีอะไรบ้าง

- 24 บทพร้อมคำศัพท์ ประโยคตัวอย่าง คำอธิบายไทย และแบบฝึกฟัง/พูด/อ่าน/เขียน
- 6 เส้นทางเรียน ค้นหาและกรองบทเรียนได้
- หน้าวันนี้ บทเรียน ฝึกทักษะ คำศัพท์ ความก้าวหน้า และบัญชี ในรูปแบบเดียวกัน
- เรียนต่อจากจุดเดิม เก็บคำศัพท์ ทบทวนข้อที่พลาด ส่งออก/นำเข้าข้อมูล
- บทจะถูกทำเครื่องหมายว่าจบเมื่อผ่านโจทย์เรียงคำและเติมคำท้ายบท
- กิจกรรมถูกนับครั้งเดียวต่อชนิด/บท ไม่เพิ่มจากการกดตอบถูกซ้ำ
- เรียนแบบไม่สมัครได้ ข้อมูลเก็บในเครื่องและนำเข้าบัญชีได้โดยเลือกเอง
- เตรียมบัญชี Supabase: สมัครอีเมล/รหัสผ่าน ยืนยันอีเมล รีเซ็ตรหัส ซิงก์ข้ามเครื่อง
- หน้าครูติดตามชื่อผู้เรียน บทที่จบ ตำแหน่งเรียนค้าง และเวลาซิงก์
- ฐานข้อมูล RLS: ผู้เรียนเข้าถึงเฉพาะข้อมูลตนเอง ครูอ่านความก้าวหน้าได้ แต่แก้ข้อมูลผู้อื่นหรือมอบสิทธิ์ครูไม่ได้

**ระบบบัญชีและหน้าครูต้องตั้งค่า Supabase ก่อน จึงจะใช้งานจริงได้**
ก่อนตั้งค่า เว็บแสดงว่าบัญชียังไม่เปิด ไม่มีการล็อกอินจำลอง
ขั้นตอนพร้อม SQL: [supabase/SETUP.md](supabase/SETUP.md)

## พัฒนาและตรวจงาน

ใช้ Node.js 22 (หรือ 20.19+)

```bash
npm ci
npm run dev
npm test
npm run build
```

`npm test` ตรวจข้อมูลบทเรียน การนำเข้า/รวมความก้าวหน้า การแยก storage ของแต่ละบัญชี และ auth REST ด้วย mock
CI เพิ่ม browser smoke tests ด้วย Playwright และตรวจการเรียนบท 24 + การเก็บความก้าวหน้า + layout มือถือ
ทดสอบ browser ในเครื่อง:

```bash
npm install --no-save --package-lock=false @playwright/test@1.56.1
npx playwright install chromium
npx playwright test
```

GitHub Actions บน main ทดสอบ สร้าง และเผยแพร่เว็บผ่าน GitHub Pages
ใน Settings → Pages เลือก Source เป็น GitHub Actions

## เนื้อหา

ข้อมูล 10 บทเดิมอยู่ใน src/lessons.js และบท 11–24 อยู่ใน src/extra-lessons.js
ข้อมูลแต่ละบทมีเป้าหมาย คำศัพท์ 5–8 คำ ตัวอย่างอย่างน้อย 3 ประโยค grammar และ practice
เพิ่มเนื้อหาแล้วรัน npm test เพื่อตรวจโจทย์และ word bank ให้ตรงกับคำตอบ
เส้นทางในหน้าจอแบ่ง 4 บทต่อหมวด (courseRanges ใน src/app.js)

## เสียงและความก้าวหน้า

เสียงต้นแบบใช้ Web Speech Synthesis จึงต่างกันตามอุปกรณ์และเบราว์เซอร์
ไมโครโฟนขอสิทธิ์เมื่อผู้เรียนกดอัดเสียงเท่านั้น เว็บไม่อัปโหลดไฟล์เสียง
Speech Recognition อาจใช้บริการของผู้ให้บริการเบราว์เซอร์ และไม่ถือเป็นคะแนนการออกเสียง
ถ้าไม่รองรับ ผู้เรียนยังฟังต้นแบบและฝึกพูดเองได้

จำนวนวันนับจากวันที่มีกิจกรรมจริง โดยไม่สมมติ streak หรือระดับความสามารถ
เปอร์เซ็นต์ทักษะแสดงกิจกรรมฝึก ไม่ใช่ผลทดสอบรับรองระดับภาษา
คำอ่านไทยเป็นเพียงตัวช่วยคร่าว ๆ ควรใช้เสียงภาษาอังกฤษเป็นต้นแบบ
คำตอบอิสระตรวจเพียงความยาวพื้นฐาน ไม่รับรองไวยากรณ์

## การซิงก์และข้อมูลเดิม

ข้อมูล guest ใช้ key เดิม english-with-yuri-v1 จึงยังอ่านความก้าวหน้าเก่าได้
ข้อมูลบัญชีแต่ละคนใช้ key ที่มี user id; การเปลี่ยนบัญชีไม่ย้าย guest progress โดยอัตโนมัติ
การซิงก์รวมบทที่จบและคำศัพท์ แล้วใช้เวลาล่าสุดสำหรับตำแหน่งเรียน
เมื่อเชื่อมต่อไม่ได้ ระบบเก็บข้อมูลในเครื่องและแจ้งว่ายังไม่ซิงก์
เครื่องเดียวกันที่เปิดหลายแท็บ หรือหลายเครื่องที่เรียนพร้อมกันมาก ๆ อาจเขียนทับข้อมูลที่ยังไม่ทันซิงก์ ควรรอ “ซิงก์แล้ว” ก่อนสลับเครื่อง

ข้อมูลบนคลาวด์และอีเมลต้องเปิดใช้ Supabase และตั้ง SMTP ของเจ้าของโปรเจกต์
การทดสอบจริงด้วยสองบัญชีและสิทธิ์ครูระบุไว้ใน SETUP.md
