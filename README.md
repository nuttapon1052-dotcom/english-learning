# English with Yuri

เว็บเรียนภาษาอังกฤษสำหรับคนไทยที่เริ่มจากศูนย์ อธิบายด้วยภาษาไทยและพาฝึกฟัง พูด อ่าน และเขียนทีละขั้น โดยไม่ต้องสมัครสมาชิก

## เปิดเว็บ

เมื่อเปิดใช้ GitHub Pages ของ repository แล้ว เว็บ production จะอยู่ที่:

**https://nuttapon1052-dotcom.github.io/english-learning/**

ทุกครั้งที่ push ไปยัง branch `main` GitHub Actions จะ build และเผยแพร่เว็บให้อัตโนมัติ หากเปิดใช้ครั้งแรก ให้ไปที่ **Settings → Pages → Source** แล้วเลือก **GitHub Actions**

## ฟีเจอร์ในเวอร์ชันนี้

- บทเรียนพร้อมใช้ 10 บท แต่ละบทมีเป้าหมาย คำศัพท์ ตัวอย่างโครงสร้าง และแบบฝึกครบ 4 ทักษะ
- Web Speech Synthesis สำหรับฟังเสียงภาษาอังกฤษ ปรับความเร็วและฟังซ้ำได้
- อัดเสียงด้วย MediaRecorder และแสดงข้อความที่เบราว์เซอร์ได้ยินเมื่อรองรับ Speech Recognition
- เส้นทางเรียน 12 สัปดาห์ แบบประเมินทางเลือก คำศัพท์ส่วนตัว และแบบทบทวนข้อที่พลาด
- บันทึกบทเรียน คำศัพท์ และความก้าวหน้าใน `localStorage`
- ส่งออก/นำเข้าข้อมูลเป็น JSON และรีเซ็ตข้อมูลพร้อมหน้าต่างยืนยัน
- ออกแบบ responsive สำหรับมือถือ พร้อมเมนูด้านล่างและการใช้งานด้วยคีย์บอร์ด

## เริ่มใช้งาน

ต้องมี Node.js 20.19+ หรือ 22.12+ จากนั้นรัน:

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงในเทอร์มินัล (โดยทั่วไปคือ `http://localhost:5173`)

สร้างไฟล์สำหรับนำไปเผยแพร่:

```bash
npm run build
npm run preview
```

ไฟล์ที่ build แล้วจะอยู่ใน `dist/` และสามารถนำไปวางบน static hosting ได้

## การใช้เสียงและไมโครโฟน

- เสียงต้นแบบใช้เสียงสังเคราะห์ของอุปกรณ์ผ่าน Web Speech API จึงอาจต่างกันตามระบบและเบราว์เซอร์
- ระบบขอสิทธิ์ไมโครโฟนเมื่อกดปุ่มอัดเสียงเท่านั้น เสียงที่อัดอยู่ในหน่วยความจำของหน้าเว็บและไม่ได้อัปโหลด
- หากเบราว์เซอร์ไม่มี Speech Recognition ผู้เรียนยังอัดและเปิดฟังเสียงตัวเองเทียบกับต้นแบบได้
- การใช้ไมโครโฟนบนอุปกรณ์จริงควรเปิดเว็บผ่าน HTTPS (ยกเว้น `localhost`)

## ข้อมูลและข้อจำกัด

ข้อมูลเก็บในอุปกรณ์ปัจจุบันด้วย `localStorage` จึงยังไม่ซิงก์ข้ามเครื่อง ควรใช้ปุ่ม **ส่งออกข้อมูล** ก่อนล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนอุปกรณ์ แบบตรวจคำตอบอิสระตรวจเพียงโครงสร้างพื้นฐานและแจ้งข้อจำกัดนี้ในหน้าบทเรียนอย่างตรงไปตรงมา

## การเพิ่มบทเรียน

ข้อมูลทั้งหมดอยู่ใน `src/lessons.js` ให้เพิ่มรายการใหม่ในอาร์เรย์ `lessons` ตามรูปแบบเดิม:

1. กำหนด `id`, emoji, ชื่อ หัวข้อย่อย และเป้าหมาย
2. เพิ่มคำศัพท์เป็น `[คำอังกฤษ, ความหมายไทย, คำอ่านโดยประมาณ]`
3. เพิ่มประโยคตัวอย่างเป็น `[ประโยคอังกฤษ, คำแปลไทย, คำอ่านโดยประมาณ]`
4. เขียนคำอธิบายโครงสร้างภาษาไทยใน `grammar`
5. ใส่ข้อมูลแบบฝึก `listen`, `choices`, `arrange`, `fill`, `read` และ `write`
6. หากเพิ่มเกินบทที่ 10 ให้อัปเดตขอบเขตหมายเลขบทใน `src/app.js` และแผน `roadmap`

คำอ่านไทยควรใช้เป็นตัวช่วยเท่านั้น และทุกบทควรมีเสียงภาษาอังกฤษเป็นต้นแบบหลักเสมอ
